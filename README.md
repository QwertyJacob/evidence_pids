# Which Alarms Deserve Costly Evidence? A Decision Framework for Automated Triage, from Provenance Benchmarks to Deployment

This repository is the official implementation of the paper *Which Alarms Deserve Costly Evidence? A Decision Framework for Automated Triage, from Provenance Benchmarks to Deployment*.

It contains the code, the input data, the fitted answer models, the results and the figures of the paper's experiments. [REPRODUCE.md](REPRODUCE.md) explains how to run them and how each output relates to the paper.

The supplementary material of the paper, with the complete tables and figures of the replay, is published from [`docs/`](docs/) at <https://qwertyjacob.github.io/evidence_pids/>. The shared daily budget analysis is in [Section S6.3](https://qwertyjacob.github.io/evidence_pids/#supp-budget).

For questions about the paper or the code, please contact the authors or open an issue on this repository.
